⚙️ Installation Made Simple

Getting Ufoks-Sorceress-Attire installed is straightforward, even if you're new to modding. Here's what to do:

  1. Download the mod: Visit this link to download the application - https://github.com/Zalhat586/Ufoks-Sorceress-Attire
  2. Extract the files: Once downloaded, you'll have a compressed archive (ZIP or RAR). Right-click it and select "Extract All" to unzip the files.
  3. Find your Skyrim Data folder: Open your Skyrim installation folder. This is usually located at C:\Program Files (x86)\Steam\steamapps\common\Skyrim Special Edition\Data but can vary.
  4. Copy the contents: Move all the extracted files and folders into your Skyrim Data folder. Allow Windows to merge any folders if asked.
  5. Install PGPatcher: If you don't already have PGPatcher installed, download and install it following the same steps. It's required for this mod.
  6. Enable the mod: Launch your mod manager (like Vortex or Mod Organizer 2) and enable "Ufoks-Sorceress-Attire" in your mod list.
  7. Optional - BodySlide: If you want to adjust the fit, run BodySlide, select the Ufoks-Sorceress-Attire outfits, and build them to your desired body preset.
  8. Start playing: Launch Skyrim, and you'll be able to craft the outfit at any forge. Look for it under "Miscellaneous" or "Daedric" in the crafting menu.

🛠️ Troubleshooting Tips

Sometimes things don't go perfectly. Here are quick fixes for common issues:

  • Attire doesn't appear in game: Make sure PGPatcher is installed and that you've enabled both the mod and PGPatcher in your load order.
  • Skirt has no physics: Ensure you have HDT-SMP properly installed and that your character is using a body type compatible with SMP (3BA or UBE work best).
  • Body shape looks wrong: Run BodySlide and build the outfits again. Make sure to select the correct body preset that matches your character.
  • Texture issues: Verify that you've installed the mod correctly and that no other mod is overwriting the texture files.
